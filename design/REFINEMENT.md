# Compact typography, motion and editorial update

Design references reviewed: [eSec Forte](https://www.esecforte.com/), [Quick Heal Home Users](https://www.quickheal.co.in/home-users), [WeSecureApp case studies](https://wesecureapp.com/resources/case-studies/). These informed density, navigation, card hierarchy and typography. Their product copy, claims, customer relationships and proprietary images were not imported.

Browser observations: eSec Forte visible hero H1 58px, paragraphs 12–14px; Quick Heal hero H1 42px. AlphaX now uses a 48px maximum homepage hero, 40px maximum inner-page heading, 25px section headings and 12–16px card/body copy, with smaller mobile scales. The top updates ticker is removed; the OTC section retains unboxed running text and a smaller enquiry card. The industry-logo strip remains separate.

The old AlphaX live site could not be fetched by the web reader. Its existing `templates/about.html` supplied the original founder introduction, About Me, Mission, Vision and expertise text. The newer Who We Are heading and generic Security with Purpose copy were replaced. This uses the user's own existing content.

Eleven original SVG illustrations depict web security, cloud protection, learning, networks, intelligence, research, identity, code, privacy, mobile security and forensics. They are conceptual illustrations, not photographs of an incident. Course/tool images float with perspective rotation; individual page backgrounds use different gradients, patterns and timings. A lightweight canvas draws an animated perspective network. It stops on reduced motion, explicit motion-off and hidden tabs. Text and forms remain stable.

`data/editorial-2026.json` contains a reviewed snapshot of ten recent 2026 [CISA KEV](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) additions, dated 27 October–6 November 2026. It is selected by catalog date, not represented as a global top-ten popularity ranking. Addition dates are not attack dates. Initial snapshots are published once; later imports still enter drafts, preserve existing editorial work and respect suppression.

Research briefs link to [ENISA Threat Landscape 2026](https://www.enisa.europa.eu/publications/enisa-threat-landscape-2026) and [Verizon DBIR 2026](https://www.verizon.com/business/resources/reports/dbir/). ENISA's 2026 edition observes 2025 events. Original blog guides cover API authorization and incident readiness, with primary-source reading links. Third-party reports are summarized and linked, not reproduced.

All new editorial records, images and existing content fields remain editable through the authenticated publishing studio. Existing customized company content is preserved when it differs from the initial default. The original company template still contains fixed presentation text for mission/vision/expertise; converting every individual phrase into CMS fields remains part of the broader admin backlog.
